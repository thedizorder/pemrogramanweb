# Perancangan CMS Profil Sekolah

## 1. Tujuan Proyek
Sistem ini merupakan Content Management System untuk administrasi website profil sekolah. Tujuan utamanya adalah memudahkan pengelolaan konten publik, data guru/staf, kegiatan sekolah, dan proses penerimaan peserta didik baru (PPDB).

## 2. Struktur Repository
```text
├── docs/
│   └── perancangan.md
├── assets/
│   ├── css/
│   ├── js/
│   └── img/
├── pages/
│   ├── dashboard.html
│   ├── data-master.html
│   └── form.html
├── index.html
└── README.md
```

## 3. Modul Utama
- Dashboard admin
- Manajemen berita dan artikel
- Direktori tenaga pendidik dan staf
- Data PPDB dan verifikasi calon siswa
- Form input data dan pengajuan konten

## 4. Prioritas Milestone 1
- Menentukan navigasi menu utama
- Membuat wireframe dashboard dan halaman data master
- Mengorganisasi struktur folder proyek secara rapi
- Menyiapkan landing page admin sebagai akses utama

## 5. Catatan Teknis
Semua halaman dibuat secara statis dalam format HTML/CSS/JS agar mudah dikembangkan lebih lanjut menjadi aplikasi web dinamis.
