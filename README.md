# School Of People People Have

Repository ini berisi prototype premium aplikasi admin sekolah berbasis static front-end yang fokus pada pengalaman manajemen profil sekolah, PPDB, konten, pengguna, jadwal, dan pengaturan sistem.

## Fitur utama

- Dashboard admin modern dan interaktif
- Halaman detail PPDB
- Editor artikel dan konten sekolah
- Analitik performa sekolah
- Manajemen pengguna dan akses
- Profil sekolah dan institusi
- Jadwal akademik
- Pengaturan sistem

## Struktur utama

- docs/: dokumen perancangan dan milestone
- assets/: file styling, JavaScript, dan image asset
- pages/: halaman aplikasi admin premium
- index.html: halaman utama portal aplikasi

## Jalankan secara lokal
Buka file index.html di browser, atau jalankan server statis sederhana seperti:

python -m http.server 8000

Lalu akses http://localhost:8000
